# Changelog

## 0.1.0

First Kweebet public preview for Hytale 0.7.4 / Java 25.

- Craftable Kweebet Workbench and Duck Race, Blackjack, Crash and Plinko machines.
- Immediate games with item bets, locked server outcomes and owned rewards when a bag is full.
- In-world ducks, ball, cards and multiplier with compact centred controls.
- Manual Crash cash-out, clear signed results, simpler item/limit settings and matching button text.
- Original models, materials and sounds, including peg plonks, active-race quacks and a three-second win fanfare.

Multiplayer spectator behaviour and broad server compatibility remain under evaluation.
