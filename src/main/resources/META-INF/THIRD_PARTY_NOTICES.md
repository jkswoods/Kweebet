# Third-party and generated assets

Kweebet's plugin source is provided under the accompanying MIT license, retaining the workspace's existing attribution.

Hytale, its API and game assets belong to their respective owners. Hytale server binaries, stock assets and downloaded toolchains are not included. Runtime references to stock game materials are resolved by a compatible Hytale installation. This is an independent mod and is not an official Hytale product.

The mod's furniture, UI graphics, display meshes and promotional artwork are original project assets. Material/branding raster sources were created with OpenAI ImageGen. Original one-shot sounds were generated through the connected ElevenLabs Sound Effects service, then exported to mono Vorbis for the game. The win fanfare is three seconds; race quacks and peg sounds are separate short cues. No stock soundtrack or third-party reference artwork is bundled.

The documentation stylesheet is adapted from the project's Hytale publishing templates. Private generation records and original takes are retained by the project; release packages contain only the selected mod assets and required source.
